Assumptions — score to metres

The TIFFs are unitless 0–1. A damage function needs water depth. We do not have street gauges, so we state a linear scale:

local depth = Hmax(storm) × TIFF score

Hmax is the CAT engine’s assumed maximum depth if the cell were fully wet (score 1.0), one ceiling per storm. The table below shows the value that arrived with each score. Those ceilings are Nairobi IDF ponding / HEC-RAS valley peaks — not a sensor on this road. Score 0 stays dry. This is not a calibrated gauge conversion.

Then the JRC Huizinga sigmoid for this construction class turns metres into a damage ratio (mabati fails early; RCC later). Land and frame survive, so the curve never reaches 100%.
